Metric formulas

Red terms lower the score. Each metric page gives the full definition, and the PSDS formulas are checked against the library for every PSDS figure.

from sedmetrics import SEDMetrics

result = SEDMetrics.eval(
    references=[(0, 0, 0.0, 1.0)],
    predictions=[(0, 0, 0.05, 1.0)],
)
print(result.f1, result.n_correct)

Read the PSDS definition

Event and segment F1
\[F_1 = \frac{2\,TP}{2\,TP + \cost{FP + FN}}\]
Segment error rate
\[ER = \frac{\cost{S + D + I}}{N_{\text{ref}}}\]
PSDS, per false-positive rate
\[\tilde{r} = \max(0,\, \mu - \cost{\alpha_{\text{ST}}\,\sigma})\]
Area under deadline recall
\[\frac{1}{N} \sum_{i=1}^{N} \max\Bigl(0,\, 1 - \cost{\frac{d_i}{H}}\Bigr)\]
Brier score, lower is better
\[\frac{\sum_i w_i\,\cost{(p_i - y_i)^2}}{\sum_i w_i}\]
